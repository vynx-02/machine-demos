# Interactive Machine Demos

Interactive 3D machine simulators — take the machine apart in your browser, with live
gauges driven by the same model that moves the parts. Built as sales & buyer enablement
demos for industrial machinery makers and exporters.

## Live pages

- **[SKY-75 Twin Screw Compressor](https://vynx-02.github.io/machine-demos/)** — a 5+6 conjugate
  screw element you can disassemble: playback clock, pocket tracker, live p–V diagram with
  over/under-compression losses, oil system, compressor map, ROI and one-tap RFQ.
- **[VFFS-160 Auger Bagger](https://vynx-02.github.io/machine-demos/vffs-bagger.html)** — a
  form-fill-seal pouch machine: film reel, forming collar, seal jaws, live configurator.

## Notes

- Single offline HTML files — no server, no dependencies. The demo runs from the file too.
- A scored 1080p film of the SKY-75 build is available on request (not hosted in this repo).
